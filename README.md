# Wafer Yield Root Cause & Defect Pattern Analyser

**Team LogicX — IBM Bobathon — Challenge S1**

A semiconductor manufacturing analytics control tower that identifies yield loss patterns, ranks evidence-supported root-cause candidates, and flags upcoming lots with elevated risk — all without LLM inference in the critical path.

---

## What This Is

A **purpose-built engineering dashboard**, not a chatbot.  Process engineers and yield engineers use it to:

1. **Monitor** fleet yield health, excursions, and chamber recurrence
2. **Investigate** individual lots — yield deviation, parameter anomalies, wafer defect patterns
3. **Analyse defect patterns** — spatial classification (center-heavy, edge-ring, scratch-line, radial, localized hotspot)
4. **Predict pre-run risk** for upcoming lots using only pre-run-safe features
5. **View ranked root-cause evidence** — deterministic weighted fusion of 7 signals
6. **Review and approve** corrective action recommendations

## Quick Start

```bash
# Docker Compose (full stack)
docker compose up --build
docker compose exec backend python data/seed_db.py
# UI: http://localhost:5173
# API: http://localhost:8000/api/docs

# Local (no Docker) — see docs/setup-guide.md
cd src/backend && pip install -e ".[dev]"
alembic upgrade head && python data/seed_db.py
uvicorn app.main:app --reload &
cd ../frontend && npm install && npm run dev
```

## Running Tests

```bash
# Backend (100 tests, ~4 min, no DB required)
cd src/backend && python -m pytest tests/ -v

# Frontend TypeScript check (0 errors)
cd src/frontend && node node_modules/typescript/bin/tsc --noEmit
```

## Key Design Rules

| Rule | Enforcement |
|---|---|
| No LLM in root-cause ranking | `root_cause.py` imports audited via `test_no_llm_imports_in_root_cause_module` |
| No future data in pre-run model | `PRE_RUN_FEATURE_WHITELIST` + `audit_for_leakage()` + leakage tests |
| Every result is traceable | `evidence_id` + `algorithm_version` + `generated_at` on all outputs |
| Engineer must approve actions | `action_reviews` table; `ActionsScreen.tsx` requires named reviewer |
| Synthetic data only | Documented in every generator file and UI footer |
