A production-grade, semiconductor manufacturing analytics control tower designed to identify wafer yield loss patterns, rank evidence-supported root-cause candidates, and flag upcoming lots with elevated operational risk—**all without LLM inference in the critical execution path.**

---

## 🚀 What This Is

This platform is a **purpose-built engineering dashboard**, built explicitly for process and yield engineers to replace slow, manual investigations with high-fidelity deterministic analytics.

*   **Fleet-Wide Health Monitoring:** Track operational yield metrics, systemic excursions, and chamber-specific recurrence intervals.
*   **Deep Lot Investigations:** Trace yield deviations, pinpoint multi-parameter anomalies, and map spatial wafer defect patterns.
*   **Spatial Defect Pattern Analysis:** Automatically classify spatial distributions including *center-heavy*, *edge-ring*, *scratch-line*, *radial*, and *localized hotspots*.
*   **Pre-Run Predictive Risk:** Forecast upcoming lot vulnerability using strictly pre-run-safe features to avoid active in-flight failures.
*   **Evidence-Based Root Cause Fusion:** Rank underlying process failure modes using a deterministic weighted fusion of **7 distinct analytics signals**.
*   **Human-in-the-Loop Governance:** Log, review, and formally approve corrective actions before deployment to the shop floor.

## ⚡ Quick Start

### 🐳 Option A: Using Docker Compose (Full Stack)

Spin up the entire application layer, database services, and seed the analytics store with a single command string:

```bash
# 1. Build and launch the container cluster
docker compose up --build -d

# 2. Seed the relational database schemas
docker compose exec backend python data/seed_db.py
```
*   **User Interface Portal:** `http://localhost:5173`
*   **Interactive OpenAPI Docs:** `http://localhost:8000/api/docs`

### 💻 Option B: Local Development Environment (Native Bare-Metal)

If you prefer executing outside of Docker containers, follow these steps:

```bash
# 1. Set up and run the Python Backend Engine
cd src/backend
pip install -e ".[dev]"
alembic upgrade head
python data/seed_db.py
uvicorn app.main:app --reload &

# 2. Set up and run the React Frontend Server
cd ../frontend
npm install
npm run dev
```

## 🛡️ Key Design Rules

To ensure strict engineering integrity, the platform enforces five fundamental guardrails at the architecture level:

| Design Guardrail | Description | Enforcement Mechanism |
| :--- | :--- | :--- |
| **Zero LLM Core Inference** | LLMs are entirely barred from calculating root-cause ranks to ensure deterministic auditability. | Verified via automated static import scanning inside `test_no_llm_imports_in_root_cause_module`. |
| **No Future Data Leakage** | Pre-run risk predictive models cannot read runtime metrics, process anomalies, or downstream defect data. | Hard-coded strict feature validation via `PRE_RUN_FEATURE_WHITELIST` + `audit_for_leakage()`. |
| **Absolute Traceability** | Every single mathematical prediction or root-cause ranking score must be fully auditable. | Strict requirement of `evidence_id`, `algorithm_version`, and `generated_at` timestamps on all schema outputs. |
| **Human-in-the-Loop Rules** | Corrective actions generated by the system cannot auto-execute without human sign-off. | Regulated via `action_reviews` DB constraints; `ActionsScreen.tsx` requires a validated reviewer name. |
| **Isolated Data Space** | Absolutely zero production PII or real-world fab IP is used or exposed. | Complete sandbox environments populated exclusively by synthetic generators with fixed random seeds. |
